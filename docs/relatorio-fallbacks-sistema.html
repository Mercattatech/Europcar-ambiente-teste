10. Recomendações e Plano de Ação para a Equipe

Recomendações Prioritárias para Revisão:

1. Recibo Internacional (Receipt): Ajustar o arquivo src/app/api/receipt/[resNumber]/route.ts para validar booking.stationCountry antes de assumir 'BR', garantindo que o locale e a moeda sejam formatados como Portugal/Europa quando a locação for no exterior.

2. Câmbio Mínimo de Emergência: O valor 6.1 em reservationMetrics.ts só entra em ação se a reserva não contiver cotação XRS. Avaliar a integração com a API do Banco Central para cotação viva em caso de ausência total.

3. PayerList da XRS: Como a XRS nem sempre envia o nó payerList completo, manter a regra de classificação por códigos de aeroporto (APF, APT) para garantir que a taxa nunca seja cobrada online indevidamente.
